Сентябрь / 2026

Dither Room · дизеринг для сайтов и UI

Браузерный инструмент: переводит 3D, 2D и текст в пиксельную графику с ограниченной палитрой и отдаёт код для вставки на сайт или файлы в популярных форматах.

Вырос из ограничения в проекте ювелирного бренда: 3D-модель изделия нельзя было выкладывать на сайт, её скачали бы и напечатали.

  • 3D уходит на сайт лентой кадров в PNG: её листает CSS steps(), жесты ловит мини-скрипт. Самой модели в коде сайта нет, скачать её нельзя
  • Быстрая единая стилизация STL, фото, GIF, видео, съёмки с камеры и текста для сайта и любого UI
  • Упорядоченный дизеринг (Байер, blue noise) и диффузия ошибки (Флойд–Стейнберг, Аткинсон) в любой палитре
  • Анимация по ключевым кадрам и гибкая настройка перетекания между состояниями
  • Автоматическое (нейросетью) и ручное удаление фона у изображений, GIF и видео
  • Экспорт: код вставки с PNG-лентой, GIF, видео MP4 и WebM, SVG, HTML-страница и ZIP-пакет
  • упорядоченный дизеринг
  • диффузия ошибки
  • MediaPipe
  • палитры на N цветов
  • CSS steps()
  • Three.js · Canvas2D

SPLAW · конфигуратор браслета

Функциональная страница для сайта ювелирного магазина, собранная в Tilda на Zero Block.

Автоматизирует расчёт скидок и оформление заказа, позволяет покупателю визуализировать браслет и подобрать сочетание его элементов ещё до производства изделия.

  • Реалистичная визуализация подвесок без 3D-моделей изделий в коде сайта
  • Интерактивный выбор подвесок и их расположения на цепочке
  • Расчёт скидки и стоимости в зависимости от количества подвесок
  • Рецепт браслета для ювелира: подвески по порядку, цепочка и размер
  • Автоматическое добавление элементов конфигурации в корзину
  • Tilda · Zero Block
  • HTML · CSS · JS без библиотек
  • drag & drop
  • калькулятор цены и скидок

DITHER ROOM

Дизайн

Веду задачу целиком: от смысла продукта через его логику к работающему коду.

  1. 01

    Задача

    Разбираюсь, кто будет пользоваться продуктом и зачем. Выясняю боли заказчиков и целевой аудитории, исследую варианты решений и анализирую конкурентов, собираю обратную связь и выделяю главные сценарии.

    • интервью
    • JTBD
    • CJM
  2. 02

    Логика

    До экранов описываю, как продукт работает: шаги пользователя, данные, правила и зависимости. Ищу, что можно автоматизировать, чтобы людям не приходилось делать это вручную.

    • user flow
    • user stories
  3. 03

    Интерфейс

    Проектирую прототипы разной сложности, чаще в Figma. Собираю дизайн-систему: переменные и токены, стили, компоненты с вариантами и состояниями на auto layout. Закладываю адаптив и структуру вёрстки.

    • прототипы
    • токены
    • UI kit
  4. 04

    Код

    Фронтенд на JavaScript и React, ботов и бэкенд на Python пишу в связке с AI-агентами: продумываю архитектуру, ставлю задачи техническим языком, результат тщательно тестирую и довожу правками. Читаю код и стремлюсь всё больше править его вручную, опираюсь на алгоритмы и компьютерную графику, продолжаю изучать языки и методы разработки. Если нужного инструмента нет, делаю свой.

    • React
    • Python
    • AI-агенты
  5. 05

    Доработка

    Тестирую в разных браузерах и на разных экранах, по обратной связи заказчика и пользователей дорабатываю продукт, пока он полностью не решает задачу.

    • кроссбраузерность
    • тестирование
